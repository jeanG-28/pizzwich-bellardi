# Pizz'Wich Bellardi — Site vitrine

Site vitrine statique (HTML / CSS / JS, sans framework) pour le restaurant **Pizz'Wich Bellardi**, à Chartres — pizzas, tacos, burgers, sandwichs, kebabs et crêpes halal, en livraison via Uber Eats et Deliveroo.

## Informations sources

- Adresse : 28 Rue de la Porte Morard, 28000 Chartres
- Téléphone : 02 37 31 95 91
- Note : 4,1/5 (68 avis Google)
- Horaires : Lun–Ven 11h–14h / 18h–23h · Sam–Dim 11h–14h / 18h–01h
- Livraison : Uber Eats & Deliveroo (~32 min)
- Prix indicatifs (relevés sur les plateformes de livraison) : voir tableau "Quelques prix" sur le site

## Structure

```
index.html
assets/
  css/style.css
  js/script.js
```

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8000
```

## Design

Typographie et palette inspirées des affichettes menu du restaurant : titres en `Anton` (impact type "menu de vitrine"), texte courant en `Poppins`, couleurs violet (murs de la salle), rouge et jaune (codes visuels snack/pizzeria).
